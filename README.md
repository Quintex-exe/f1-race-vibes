# 🏎️ F1 Race Vibes

A vibey, animated F1 racing dashboard with driver standings, live track animations, and season stats. Built with pure HTML/CSS/JS for maximum speed.

## ✨ Features

- 🏁 **Animated Racing Track** - Watch an F1 car race across a dynamic track with moving lane markers
- 🏆 **Driver Standings** - Real-time leaderboard with authentic team colors and smooth hover effects
- 📊 **Interactive Statistics** - Season stats that pulse and respond to user interaction
- 🎨 **Gradient Animations** - Smooth, eye-catching gradients that bring the F1 energy to life
- 📱 **Fully Responsive** - Looks great on desktop, tablet, and mobile devices
- ⚡ **Zero Dependencies** - Pure vanilla JavaScript, no frameworks, no build process
- 🎮 **Click Interactions** - Interactive driver cards with satisfying animations
- 🌈 **Team Color Coding** - Each driver card features their team's signature color
